# AssetMX brand marks

Master SVGs for the ribbon logo. The files actually served live in
`site/public/` and `public/`; these are the sources to export from.

| File | Use |
| --- | --- |
| `mark.svg` | Ribbon mark alone, 190x100 |
| `lockup-horizontal.svg` | Mark + wordmark + tagline. Shipped as `logo.svg` (schema.org `Organization.logo`) |
| `lockup-stacked.svg` | Mark over wordmark + tagline. Print, large-format |
| `*-reversed.svg` | For forest and forest-800 grounds |
| `icon.svg` | Square tile, slimmed strokes. Shipped as `favicon.svg` / `apple-touch-icon.png` |

Palette: forest `#3D472B` · sage `#7F9466` (reversed `#AEBF92`) · sand-deep `#C2B490` ·
canvas `#F5EAD8` · ink `#201E1D`.

The wordmark is live `<text>` in Figtree 800. **Convert to outlines before sending
anything to a printer or a third party** - they will not have the font.
